# 10 — ImportCheck

## Objetivo

Criar uma ferramenta para analisar uma pasta de processo de importação e comparar documentos, identificando divergências e pontos de atenção.

## Entrada prevista

- Invoice.xlsx
- Packing_List.xlsx
- PL.xlsx
- NF.xml
- Outros documentos estruturados

## Validações previstas

- Quantidades
- Produtos e códigos
- NCM
- Peso líquido e bruto
- Campos obrigatórios
- Divergências entre documentos

## Estrutura

- `src/` — código principal
- `tests/` — testes automatizados
- `dados_exemplo/` — dados fictícios para desenvolvimento

Este projeto será construído gradualmente durante o aprendizado.
