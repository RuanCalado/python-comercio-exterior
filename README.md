# 🐍 Python para Comércio Exterior

Estudos e projetos práticos de Python aplicados à automação de processos de Comércio Exterior, análise de dados, Excel, documentos e integração com IA.

## 🎯 Objetivo

Aprender Python construindo soluções que tenham aplicação direta em rotinas de importação, exportação e logística.

## 🗺️ Roadmap

1. Fundamentos de Python
2. Python + Excel
3. Conciliação Invoice × Packing List × PL
4. Validação e auditoria de processos
5. Leitura e tratamento de documentos
6. Automação de arquivos e processos
7. Python + IA
8. APIs e integrações
9. Interfaces
10. Projeto final: **ImportCheck**

## 📁 Organização

Cada pasta representa uma etapa da evolução. Os exercícios iniciais serão simples e, gradualmente, transformados em ferramentas aplicáveis ao Comércio Exterior.

## 🔐 Segurança

Este repositório é público. **Não devem ser enviados dados reais de clientes ou empresas**, como invoices, XMLs, CNPJs, valores comerciais, documentos aduaneiros, credenciais, senhas ou tokens de API. Os exemplos devem utilizar dados fictícios.

## 🚀 Projeto final — ImportCheck

A ideia é desenvolver uma ferramenta capaz de analisar uma pasta de processo e comparar documentos como Invoice, Packing List, PL e XML, identificando divergências de quantidade, peso, NCM e campos obrigatórios.

## 📈 Evolução

O histórico de commits fará parte do aprendizado. A intenção é registrar a evolução desde os primeiros programas até as automações completas.
